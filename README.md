# CivicSpark

> A civic tech platform that empowers citizens to report 
> local issues — potholes, broken infrastructure, safety 
> hazards — directly to the relevant government authority, 
> with real-time status tracking.

## Background
Built at Civic Abia in 2025 as a solution to the gap 
between citizens experiencing local problems and the government 
bodies responsible for fixing them. Most issues go unreported 
because the process is too friction-heavy. CivicSpark removes 
that friction.

## What It Does
- Citizens submit issue reports with location and photo evidence
- Reports are categorised and routed to the relevant authority
- Citizens can track the status of their submission
- Dashboard view for authorities to manage and respond to reports

## Built With
- React 
- JavaScript
- Tailwind CSS


## Note
This was built as a hackathon demo. Core flows are functional; 
some features are in prototype state.
